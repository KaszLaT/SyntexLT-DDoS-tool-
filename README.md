# Syntex Load Stresser

Инструмент для нагрузочного тестирования сетевой инфраструктуры.
Позволяет проверить устойчивость серверов к высоким нагрузкам.

## Возможности

- HTTP-флуд — бомбардировка веб-сервера запросами
- UDP-флуд — насыщение пропускной способности канала
- Slowloris — медленная атака с удержанием соединений
- SYN-флуд — заполнение очереди полуоткрытых соединений
- Многопоточная архитектура — до 1000+ потоков
- Рандомизация заголовков и путей для обхода кэширования
- Статистика в реальном времени
- Поддержка заданной длительности теста

## Установка


# Требуется Python 3.7+
pip install requests

python main.py for instructions

example

python main.py 0.0.0.0 -m syn/udp/http/* -t *
